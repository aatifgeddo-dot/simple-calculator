 # 🧮 Simple Web-Based Calculator

A clean, modern, and lightweight web-based calculator built entirely using Python. This project demonstrates how to handle logical and mathematical operations and render them seamlessly through a web interface.

## 🚀 Features
* **Core Operations:** Supports addition, subtraction, multiplication, and division.
* **Web UI:** Interactive and responsive user interface accessible via any browser.
* **Pure Python:** Backend logic and presentation layer powered 100% by Python.

## 🛠️ Tech Stack
* **Language:** Python 3
* **Framework:** PyScript

## 💻 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate to the project directory:**
   ```bash
   cd simple-calculator
   ```

3. **Run the application:**
   ```bash
   python main.py
   ```
